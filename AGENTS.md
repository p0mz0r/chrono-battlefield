## Agent skills

### Issue tracker

Issues live in GitHub Issues for `p0mz0r/chrono-battlefield`; use Git for version control. Starting or closing a ticket: follow the wayfinding steps in `docs/agents/issue-tracker.md` (assign, resolve, close, add a pointer to the map).

### RA2 install and OBS

Reading game files, running or finding the install tests, checking a render or the editor UI in a browser, or measuring frame rate: see `docs/agents/ra2-install.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one root `GLOSSARY.md` and `docs/adr/`. See `docs/agents/domain.md`.

### Research notes

Findings go in `docs/research/` as Markdown, with cited sources.
