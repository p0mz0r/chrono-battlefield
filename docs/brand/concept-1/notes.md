# Concept 1: Charge

A charging rhino tank carries a checked flag through red and cyan speed streaks. The horizontal silhouette suits stream title cards.

- Colours: crimson `#C82D39`, chrono cyan `#22BFD9`, steel `#AFC1CD`, ink `#182435`, dark `#111B27`, light `#F0F2EE`.
- Lettering: Barlow Condensed Black by the Barlow Project Authors, SIL Open Font License 1.1. The font and license are in `../fonts/`.
- Illustration: newly generated original artwork for this concept; no game assets or franchise marks were used.
- Small-size check: the 72 px icon was inspected at its actual size and its rhino/armor silhouette remains recognizable. The 32 px icon keeps the main silhouette for favicon use.
